The program, assignment5.cc is compiled by running “g++ assignment5.cc”. To use the program, use “./a.out inputfilename [FCFS|SJF|RR]  [timequantum]”. FCFS for First come first serve, SJF for shortest job first, and RR for round robin scheduling algorithms respectively. Timequantum is only used with the round-robin algorithm, and trying to run the round robin algorithm without a positive integer time quantum (or no time quantum) will print an error message and exit the program. Likewise, not specifying a scheduling algorithm or an input file name (or an invalid input file name) will also print an error message and end the program. Input.1, input.3, and input.4 are all valid input files for the program, while input.2 is an invalid input file used to check that the program will stop executing upon reading a file with an invalid number of processes specified in the file. Input.1 uses the input data of the sample input from the assignment.
